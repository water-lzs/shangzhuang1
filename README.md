# 穿越京西稻 · GitHub Pages 版

将本目录内全部文件和文件夹上传到 GitHub 仓库根目录，保证 index.html 在根目录。不要只上传 HTML 或 ZIP。

Settings → Pages → Deploy from a branch → main → /(root) → Save。发布后打开 Pages 显示的网址。

无需 Node 服务或 npm 安装。保留 models、assets、vendor 目录结构。本机直接双击 HTML 不能可靠加载模块，请通过 GitHub Pages 打开。

保留当前游戏内容及浏览器本地存档。社交为本机模拟，真实多人互动、寄米未接入后端。
